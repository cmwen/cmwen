# Hi, I'm Min 👋

I'm a software engineer based in Sydney, exploring how AI agents are changing the way software is designed, built, and operated.

I build open-source experiments around **agentic engineering, composable applications, local-first systems, developer tooling, and user-owned software**.

A recurring theme in my work is turning software into smaller, explicit building blocks — capabilities, state, tools, and interfaces — that can be composed by both humans and AI agents.

## What I'm exploring

- 🤖 **Agentic software engineering** — workflows, workspaces, state, and orchestration for coding agents
- 🧩 **Composable applications** — software that can expose and reuse capabilities across application boundaries
- 🧠 **Persistent context and knowledge** — durable state and context for long-running AI-assisted workflows
- 🏠 **Local-first and user-owned software** — applications where users retain control of their data and infrastructure
- 🛠 **Developer tooling** — tools that make increasingly agent-driven development observable, controllable, and practical

## Featured Open Source

### 🤖 [Agentic Engineering Workspace](https://github.com/open-agent-workspace/reference-implmentation)

A local-first reference architecture for coordinating coding agents across one or more Git repositories.

It explores isolated agent runs using Git worktrees, durable workspace knowledge, explicit candidate integration, and resumable operational state without turning independent repositories into a monorepo.

**Focus:** coding agents · developer infrastructure · local-first · Git workflows

---

### 🧩 [Page Apps](https://github.com/page-apps/app-framework)

An experimental architecture for small, user-owned web applications built around GitHub repositories and GitHub Pages.

The project explores explicit application and data boundaries, private repository-backed state, capability-based access, plugin runtimes, and agent-generated applications.

**Focus:** personal software · composable apps · GitHub as infrastructure · agentic workflows

---

### 🔗 [Web Relay](https://github.com/web-relay/web-relay)

A local-first browser capability runtime that lets PWAs, browser extensions, and independent providers expose and invoke actions across application boundaries.

It includes a reusable TypeScript SDK, browser launcher, capability discovery protocol, and cross-extension integration.

**Focus:** composable software · browser extensions · developer tools · local-first

---

### 📊 [Min Infograph](https://github.com/min-infograph/min-infograph)

A structured infographic system that turns portable JSON documents into composed visual content.

It combines a reusable intermediate representation, React rendering, Mermaid diagrams, CLI tooling, and an AI-agent authoring workflow.

**Focus:** structured content · visualization · AI tooling · reusable rendering systems

## Engineering Direction

I'm particularly interested in what happens when software development moves from:

**human writes code → tools assist**

toward:

**human defines intent → agents operate tools → systems preserve context → humans supervise outcomes**

That shift raises interesting engineering problems around state, trust boundaries, observability, integration, isolation, and ownership.

Those are the problems I enjoy exploring.

## Background
